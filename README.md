# Portfolio — Amina Sanhaji, Product Builder

Site vitrine statique (une page) : `index.html`, `merci.html`, `amina.jpg`, `netlify.toml`. Aucune étape de build.

Le formulaire de contact utilise Netlify Forms : les messages arrivent dans Netlify > Forms (activez les notifications e-mail dans Forms > Form notifications).

Décisions produit et design : `PRODUCT.md`, `DESIGN.md`.

## Mettre à jour
Modifier `index.html`, puis `git commit` et `git push` : Netlify redéploie automatiquement.

## Déploiement
Netlify → Add new site → Import an existing project → GitHub → ce dépôt.
Build command : vide · Publish directory : `.`
